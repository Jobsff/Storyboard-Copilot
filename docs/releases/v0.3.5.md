# v0.3.5 · 公司资产自动归档（OSS）

## 新增

- **生成图片自动归档公司画廊**：出图成功后自动上传公司阿里 OSS（巨游资产画廊 tu.jyounet.com 按目录浏览），拿到永久公共读链接，可直接复制发给同事查看引用，不再互相传文件
  - 归档按**工程名自动分目录**：`工程名/年-月/图片`——游戏 A、游戏 B 各自的工程出的图天然分开，画廊里按工程浏览
  - 所有渠道统一走同一条归档通道，文件命名统一（任务号_渠道_模型），画廊整齐可辨
  - **归档失败绝不影响出图**：未配置、断网、上传超时都只静默跳过，出图照常
- **设置 → 资产归档**：填入公司 OSS AccessKey ID / Secret（一次配置），带「测试连接」按钮验证凭据
- **复制链接**：生成记录每行新增「复制链接」按钮；图片节点成功角标悬停可见归档直链

## 说明

- 工程改名后新图进入新目录，旧图保留原目录（不搬家）
- 凭据保存在本机（与渠道密钥同方式），不随安装包分发
