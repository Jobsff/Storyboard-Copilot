# v0.3.0 · 渠道可靠性升级

面向美术日常出图的两大痛点：「渠道抽风导致失败/极慢且不知道原因」「渠道太多不会选」。

## 新增

- **智能出图（推荐默认）**：模型列表置顶「智能出图 · 标准 / 高质量」，自动按价格优先选择渠道，失败自动切换下一渠道重试，全程无需手动挑选渠道。专家手动选渠道的用法完整保留，已有手动选择不受影响。
- **生成过程看得见**：渠道响应异常或自动换渠道时，生成中节点实时显示一行黄色说明（如「已自动切换 666API 重试」「GRSAI 当前不可用，本次自动从 666API 开始」），不再是无声转圈。
- **失败原因说人话 + 可行动**：失败弹窗按六类给出建议——渠道超时/渠道故障（建议换智能出图）、密钥无效（一键打开设置）、余额不足（一键去充值）、提示词触发安全过滤（提示中文提示词偶发误杀，直接重试通常能过）；保留「复制详情」报告。
- **渠道健康面板**：设置新增「渠道健康」，一键免费检测全部渠道（绿/黄/红徽标 + 延迟 + 降级链可用档数），检测不产生任何生成费用；应用启动自动静默检测一次；供应商选择页 Tab 带健康圆点，每渠道附一句定位建议。
- **生成记录与出图角标**：每张成功图右下角标注「渠道 · 模型 · 耗时 · 智能链」；设置新增「生成记录」，可查最近 100 次生成的渠道/耗时/模式/失败原因与链切换轨迹。

## 修复

- 根除「生成中无限转圈」：所有渠道请求补齐超时（连接 10 秒/单请求 300 秒），渠道连续 3 次无响应或整体超时即明确报错并（智能出图下）自动换渠道，不再永动等待。
- 修复生成结果整段 base64 写入数据库导致 projects.db 持续膨胀的问题：大图改存独立媒体目录，数据库不再随出图次数线性变大；过期的媒体文件 7 天后自动清理。

## 优化

- 渠道配置未同步到生成引擎时，设置页顶部显示黄条并支持一键重试，不再静默失败。
- 生成失败后可从错误弹窗一键触发「检测所有渠道」并跳转健康面板。
