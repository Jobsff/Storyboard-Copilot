# v0.4.6 · 智能出图双引擎 + 画廊集成 + 抠图三工具

## 新增

- **智能出图升级五张卡**：谷歌 标准 / 谷歌 高质量（原两档更名）+ **GPT 标准·高速**（Flare 2.5）/ **GPT 高质量**（Sunburst 2.5）/ **GPT 透明底**（GPT Image 2 三渠道降级链：grsai 真透明 → 666api → 巨游），美术零渠道选择负担，各档位自动降级兜底
- **巨游资产画廊集成**：标题栏「画廊」按钮在应用内浏览公司图库；生成图片自动归档公司 OSS（按工程名分目录），每张图带生成简介（渠道/模型/比例/尺寸/提示词），画廊卡片显示简介、灯箱可复制提示词；生成记录行与图片角标可一键复制永久直链
- **抠图**（工具栏魔法棒）：纯色/高饱和背景抠图，点击背景取色（可多点采样）、影子/暗地面自动识别、边缘柔和去污染，离线可用
- **AI 去底**（工具栏橡皮擦）：任意背景**一键整件去底**——约 0.3 秒出发丝级透明底，零交互（内网 BiRefNet 服务）
- **AI 抠图**（工具栏扫描框）：指定抠局部物件，左键点主体/右键点排除，点选迭代精修（内网 SAM 服务，1024 高清蒙版）

## 优化

- 抠图算法按背景色自动选管线：绿色系走强去污染管线、其他纯色走温和管线（兼顾绿幕溢色与品红画质）
- AI 抠图蒙版增强：孔洞自动填充、引导滤波边缘细化、自动布点
- 智能出图 Pro 档链序：grsai Pro 风格优先 → aifast → 666api 降级
