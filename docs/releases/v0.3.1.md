# v0.3.1 · 渠道管理统一（简化版）

## 新增

- **GRSAI 渠道密钥入口**：设置 → 服务商新增 GRSAI 卡片（含 nano-banana-pro 变体选择），配置密钥后智能出图降级链的低价首选档（¥0.06/张）正式生效。
- **aifast 预置渠道**：设置新增 aifast 卡片，填入密钥后可一键「获取模型」并勾选需要的模型，勾选后即可在画布使用。
- **NEWAPI 接口可加入智能出图链**：每个 NEWAPI 接口（含 aifast）新增「加入智能出图降级链」开关；开启后，接口上与降级链成员同名的模型自动追加为链尾备选渠道，失败轨迹中显示接口名称。

## 优化

- 渠道密钥区按使用优先级重新排序：GRSAI → aifast → 666API → 巨游API → AGNES AI → Ollama。
- 「自定义接口」更名为「NEWAPI 接口」，定位明确为添加 NEWAPI / OpenAI 兼容格式的中转商。
- 渠道健康检测覆盖范围扩大：NEWAPI 接口与 aifast 一并纳入免费探活，健康面板可查看其状态与延迟。
